FINDIT CAMPUS v7.3 — UPLOAD INSTRUCTIONS (TAGALOG)

Ang version na ito ay kapareho ng v7.2 camera sizing/capture layout pero tinanggal ang scanning effects sa ID at selfie.

1. I-download at i-extract ang ZIP.
2. Buksan ang GitHub repository na ronalduy/findit-campus-demo.
3. Piliin ang Add file → Upload files.
4. I-upload ang lahat ng laman ng folder na ito DIREKTA sa root/main folder ng repository; huwag ilagay sa bagong nested folder.
5. Palitan ang existing index.html, styles.css, app.js, at sw.js kapag tinanong. Panatilihin ang assets at icons folders.
6. I-click ang Commit changes at hintaying green/successful ang GitHub Pages deployment.
7. Sa Chrome, buksan ang /reset-cache.html sa iyong GitHub Pages site at pindutin ang Clear old cache & reopen. Pagkatapos ay buksan ulit ang main website.

ANO ANG DAPAT MAKITA
- Walang gumagalaw na scan beam sa ID o selfie.
- Walang pulsing/glowing animated corners.
- Walang dashed face scan line.
- Mananatiling landscape ang ID frame at portrait oval ang selfie guide.
- Mananatili ang Capture, Retake, at Use Photo controls.

PAALALA: Camera test sa Chrome/Safari gamit ang HTTPS. Gumamit ng sample ID; huwag mag-test ng totoong school ID sa public demo.
