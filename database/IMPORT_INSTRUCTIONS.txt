DATABASE IMPORT / SETUP
=======================
1. Start MySQL in XAMPP.
2. Open http://localhost/phpmyadmin.
3. Choose Import and select database/findit_campus.sql from this project folder.
4. Start the import and wait for the success message. The SQL creates the database and tables if missing; it does not DROP existing data.
5. Open config.php and update DB_PASS only if your XAMPP MySQL root account has a password.
6. Open the site at http://localhost/FindIT_Campus_XAMPP_System/.
7. First Admin login: username admin, password 1234. Change the Admin password immediately.
8. To check phone/laptop sharing, open Phone / Laptop Test in the Admin menu and follow the on-screen guide.

Never publish the XAMPP server through router port forwarding. Use fictional records for testing.
