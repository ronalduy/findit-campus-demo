FindIT Campus — Final Orientation Behavior

Requested behavior implemented in this package:
- Keep the entire webpage and modal in portrait.
- Do not request fullscreen.
- Do not request screen orientation lock.
- Only the school ID preview frame uses a landscape aspect ratio.
- Keep the phone upright and hold the physical ID horizontally, centered in the wide frame.
- The selfie preview remains portrait with an oval face guide.
- Video pixels are not rotated based solely on videoWidth/videoHeight.
- Saved capture uses a centered crop based on the visible frame dimensions, matching object-fit: cover.
- Service worker cache: v13.

The code passed JavaScript syntax checks. It has not been directly tested on the user's phone hardware; verify with a sample ID after deployment.
